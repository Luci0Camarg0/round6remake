# Os 456

Fã-jogo leve em 3D inspirado na série **Round 6**. Roda direto no navegador, no PC ou no celular, sem instalar nada.

Você aceitou o convite: seis brincadeiras de criança separam você do prêmio de ₩ 45,6 bilhões. Cada jogador eliminado coloca ₩ 100 milhões no cofrinho.

## Como jogar

Abra o `index.html` no navegador. Também dá pra publicar de graça pelo GitHub Pages (Settings → Pages → branch `main`, pasta raiz).

| Rodada | Jogo | Estado | Controles |
| --- | --- | --- | --- |
| 1 | Batatinha Frita 1, 2, 3 | Jogável | Segure ↑ ou W pra correr, ← → pra desviar. No celular aparecem botões na tela. |
| 2 | Dalgona | Jogável | Segure e arraste a agulha devagar sobre a linha, com o mouse ou o dedo. |
| 3 | Cabo de Guerra | Em breve | |
| 4 | Bolinha de Gude | Em breve | |
| 5 | Ponte de Vidro | Em breve | |
| 6 | Jogo da Lula | Em breve | |

Modo multiplayer: planejado. Vai precisar de um servidor para as salas online.

## Tecnologia

- Um arquivo só (`index.html`), sem etapa de build.
- [Three.js r128](https://threejs.org/) carregado pelo cdnjs para a parte 3D.
- Canvas 2D para a Dalgona e Web Audio para os sons.
- Todos os modelos (jogadores, guardas, boneca) são feitos com formas simples no código. Não há arquivos de imagem ou modelo copiados da série.

## Aviso

Projeto de fã, sem fins lucrativos e sem ligação com a Netflix ou com os criadores de Round 6.
